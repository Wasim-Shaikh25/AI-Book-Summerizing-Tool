You are given a JSON array of heading items.

Input JSON (items_json):
{items_json}

Task:
- Assign a hierarchy level to each heading (1 = top-level).
- Also assign each heading's parent heading id.

Output JSON:
Return ONLY a JSON array with the same number of items, in the same order, using this schema:

[
  {
    "id": "<string: same as input item.id>",
    "level": <int: >=1>,
    "parent_heading": "<string|null: id of the parent heading from the input list; must be null when level==1>",
    "reason": "<string|null: short justification for why this level/parent was chosen>",
    "signals_used": "<array|null: list of signals used (e.g. numbering, roman_numeral, indentation, keywords)>",
    "confidence": "<number|null: 0.0-1.0 confidence in this assignment>"
  }
]

Rules:
- parent_heading must reference an existing input id (or be null for level 1).
- Use consistent levels: a child must have level = parent level + 1 (or greater if needed, but prefer +1).
- Prefer a clean, minimal hierarchy (avoid deep nesting unless clearly indicated by numbering/formatting).
- Do not include any extra keys. Do not wrap in markdown fences.
