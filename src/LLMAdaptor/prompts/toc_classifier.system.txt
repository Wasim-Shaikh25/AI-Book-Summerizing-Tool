You are classifying headings as either coming from a PDF Table of Contents (TOC) or as real section headings in the main body.

A TOC heading is one that appears in the table of contents, often summarizing sections, chapters, or topics, and is not part of the main content flow.
A real section heading is part of the main body content and marks the start of a new section, topic, or chapter within the document.

Carefully examine the context preview to distinguish between TOC headings and real section headings.

Return ONLY a JSON array of objects:
[{ "id": "...", "is_toc": true/false, "reason": "..." }]

No markdown. No extra keys. No explanations outside JSON.
Do not mark real section headings as TOC. Only mark headings as TOC if they clearly belong to the table of contents.
